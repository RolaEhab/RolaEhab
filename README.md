## Selected Projects

### [REACTA — Drug-Drug Interaction Prediction](https://github.com/RolaEhab/Reacta-Drug-Drug-Interaction)

An AI-powered drug-drug interaction prediction system designed to identify potential interactions between medications using biomedical graph data and deep learning.

The project combines heterogeneous biomedical information from sources including **DrugBank, TWOSIDES, and STRING**, experimenting with graph neural network architectures such as **GAT and R-GCN** alongside molecular and semantic drug representations.

My work focused mainly on **data exploration and preparation, biomedical feature engineering, GNN experimentation, model evaluation, and technical analysis** as part of the project's data and machine-learning team.

The final system integrates the prediction pipeline with a web platform, inference APIs, and an AI-assisted explanation layer.

`Python` `PyTorch` `PyTorch Geometric` `Graph Neural Networks` `Neo4j` `BioBERT` `FastAPI` `.NET`

---

### [DriveGuard — Driver Monitoring System](https://github.com/RolaEhab/DriveGuard-Driver-Monitoring-System)

A real-time computer vision system designed to monitor driver behavior and detect both **drowsiness and distracted driving** through a webcam feed.

DriveGuard combines **YOLO-based behavior detection** with eye-aspect-ratio temporal analysis to distinguish normal blinking from sustained drowsiness. It can identify distracted behaviors including **phone use, smoking, and eating**, while triggering visual and audio alerts when unsafe behavior is detected.

The distraction detection model achieved an **89% mAP50**, and the system also supports optional event logging with timestamps, event duration, and alert status.

`Python` `OpenCV` `YOLO` `PyTorch` `TensorFlow` `NumPy` `Pandas` `Flask`
